# MIDI map

How the router rewrites DDJ-FLX4 messages for the virtual `FLX4-4DECK` device. Values are hex.
`ch` is the MIDI channel (0-based); `d` is the active deck of the side (0-3, shown in the UI as 1-4).
Left side = decks 0/2, right side = decks 1/3.

## FLX4 → rekordbox

| FLX4 sends | Meaning | Router sends |
|---|---|---|
| ch 0/1, note `68` + SHIFT (`9x 68`) | SHIFT + headphone CUE | **Swap that side** (consumed) |
| ch 6, note `63` | MASTER CUE | **Swap both sides** (consumed) |
| ch 0/1, any note | deck buttons (play `0B`, cue `0C`, sync `58`, loops, SHIFT `3F`...) | same note on **ch d** |
| ch 0/1, CC `00/05` + `20/25` | tempo (hi-res) | same CC on **ch d**, with pickup |
| ch 0/1, CC `04 07 0B 0F 13` + LSB | trim, EQ hi/mid/low, channel fader | same CC on **ch d**, with pickup |
| ch 0/1, CC `21 22 23 29` | jog: wheel, touched, touched bend, SHIFT | note `21/23` (nudge) or `24/25` (search) on **ch d**, held while turning |
| ch 7/8 (left), 9/10 (right) | pads / SHIFT + pads | **ch 7 + 2d** / **ch 8 + 2d** |
| ch 6, note `46` / `47` | LOAD left / right | ch 6, note **`46 + d`** |
| ch 6, CC `17/37` (left), `18/38` (right) | CFX filter knob | ch 6, CC **`17 + d`** / **`37 + d`**, with pickup |
| ch 4/5, note `10` / `11` | Beat FX channel 1 / 2 | same, or **`12` / `13`** while SHIFT is held |
| anything else | browser `B6 40`, crossfader `B6 1F`, FX unit ch 4/5, headphones, master... | unchanged |

## rekordbox → FLX4 (feedback)

| rekordbox sends (virtual device) | Goes to FLX4 as | Shown when |
|---|---|---|
| ch 0-3 (deck LEDs, level meter `B? 02`) | ch `d % 2` | deck is active on its side |
| ch 7-14 (pad LEDs) | ch 7/8 (left) or 9/10 (right) | deck is active |
| ch 15 note `00-03` (loaded) | ch 15 note `00/01` | deck is active |
| ch 15 note `04-07` (loop active) | ch 15 note `04/05` | deck is active |
| anything else | unchanged | always |

## Virtual device mapping (`FLX4-4DECK.midi.csv`)

Generated by `tools/gen_mappings.py` from rekordbox's bundled `DDJ-FLX4.midi.csv`:

- Every FLX4 global row unchanged (browser, crossfader, FX units, master, headphones, settings).
- Every deck row with decks 3/4 added. Deck columns are channel offsets or full messages; deck N =
  deck1 + (N-1) × (deck2 − deck1), e.g. `0,1 → 2,3`, pads `7,9 → 11,13`, load `9646,9647 → 9648,9649`,
  indicators `9F00,9F01 → 9F02,9F03`.
- `CFXParameterCH3/CH4` at `B619/B61A`.
- `FX1Assign.CH1-4/MASTER` at `9410-9414`, `FX2Assign.*` at `9510-9514` (same as the DDJ-GRV6 for FX1).
- `PitchBendUp/Down` at `9021/9023`, `SearchFwd/Rev` at `9024/9025` per deck (notes the FLX4 never uses).
- `TapBpm` (SHIFT + headphone CUE) dropped: that combo is the swap.
